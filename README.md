# Smart Resume Builder

A responsive web-based Resume Builder that allows users to create professional resumes by selecting a template and filling out a simple form. The application generates a clean, printable, and downloadable resume instantly using JavaScript.

## Features

- Multiple resume templates
- Interactive resume form
- Instant resume generation
- Download-ready resume
- Responsive design
- User authentication (Login & Signup)
- Modern UI with Bootstrap and custom CSS

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- MySQL

## How It Works

1. Select a resume template.
2. Fill in your personal, educational, and professional details.
3. Preview your resume instantly.
4. Download or print the generated resume.

## Future Improvements

- PDF export
- More resume templates
- AI-powered resume suggestions
- Resume sharing via link
